# Talio for Creators — лендинг

Статический одностраничный сайт (лендинг) Talio for Creators. Собран из дизайна
Claude Design и переведён в самодостаточный HTML без фреймворков и сборки.

## Состав
- `index.html` — весь сайт (разметка + стили + скрипты инлайн)
- `assets/` — 4 скриншота приложения, favicon

Внешняя зависимость только одна — шрифты Google Fonts (Manrope, Golos Text).

## Публикация
Это чистая статика. Подойдёт любой статический хостинг:
- **Netlify / Vercel / Cloudflare Pages** — перетащите папку или подключите репозиторий, публиковать корень.
- **GitHub Pages** — залейте файлы в ветку, включите Pages.
- **Свой сервер** — просто отдавайте папку как статику.

Локальная проверка: `python3 -m http.server` и открыть http://localhost:8000

## Что стоит заменить перед публикацией
- **Логотип** — используется фирменный `assets/logo-talio.JPG` в шапке и подвале.
- **Скринкаст в hero** — слот с кнопкой play рассчитан на MP4 (автоплей, без звука, зациклено) с экрана реального приложения.
- Ссылки Telegram: `t.me/taliofit_bot`, `t.me/gokravchenko` — проверьте актуальность.
